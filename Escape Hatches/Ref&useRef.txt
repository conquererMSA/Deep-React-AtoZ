**Ref rendering trigger korena, zodio ref user interaction e change hoy. re-render na howarkarone amra ref er updated value dekhte paina. Ref rendering er somy access kora zayna. Ref rendering er por browser DOM e commit sheshe JSX element access korte pare. Ref rendering leads unreliable code.**

Kuno componnent er kuno DOM element/JSX er reference dhora ba component er emon kuno data zeta user er event e change holeo render trigger korbe na, emon sob case e ref use kora hoy. useRef hook e initial reference value argument hisabe dile amra useRef er return e plain JS object ref pai. ref object er current property er moddhye amra ref e point value/reference peye zai.
Ref component er storage hisabeo use kora hote pare (ScrollIntoView, array scrolling). Storage er value change hobe kintu re-render trigge hobe na. Ref rendering process er vaire inplaced mutate kora zay. Kintu state e change update guluke batch kore queue te pathiye dey, tarpor kromanushare update gulu rendering hoy.

Component er logic e amra ref value ke read, write and modify korte pari, kintu re-render er moddhye ref available hoy na biday read, write and modify kora zayna. Render and Commit er sheshe zokhon browser DOM e html node/ JSX element available hoy tokhon ref er current property corrosponding ref value diye set hoy. browser e DOM node availabe hower agg porzonto ref initial value-i pawya zay.
