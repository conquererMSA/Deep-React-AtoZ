Kuno componnent er kuno DOM element/JSX er reference dhora ba component er emon kuno data zeta user er event e change holeo render trigger korbe na, emon sob case e ref use kora hoy. useRef hook e initial reference value argument hisabe dile amra useRef er return e plain JS object ref pai. ref object er current property er moddhye amra ref e point value/reference peye zai.
Ref component er storage hisabeo use kora hote pare (ScrollIntoView, array scrolling). Storage er value change hobe kintu re-render trigge hobe na.
Component er logic e amra ref value ke read, write and modify korte pari, kintu re-render er moddhye ref available hoy na biday read, write and modify kora zayna.
