Reducer let us consolidate application's all state update logic in a single place.
Reducer component er sathe tide thake na, borong component er baire manage kora hoy.
Reducer performance e efect kore na, eta shudhumatro ekta pattern za code readibility and code debugging baray.
Reducer ekta pure function za same input er jonno same output dey. Reucer er moddhye side effect, time scheduling, and request send kora ucit na.
export default const taskReducer=(tasks, action)=>{}
ekhane taskReducer duita param tasks and action recieve kore. ekhane action hocce ekta object and tasks hocce sei reducer er initial data. User er proti interaction e kichu essential data dispatch hoy za reducer er action er moddhye ase. Action er moddhye thake type and tasks poribortoner jonno proyujonio data. Action er type onuzaye reducer state tasks mutate kora hoy.
