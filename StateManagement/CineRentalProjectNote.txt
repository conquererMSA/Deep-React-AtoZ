Header component e ThemeContext use kore current mode extract korte hobe and mode setter function setDarkMode o niye aste hobe. Trpor mode JSX element/Icon mode onuzaye setDarkMode setter function diye toggle korte hobe.
ThemeContext name ekta context create kora hobe ebong themecontext er provider e value hisabe darkMode and setDarkMode state provide kora hobe.
export default const App=()=>{
    const [darkMode, setDarkMode]=useState(true);
    return(
        <>
        <ThemeContext value={{darkMode, setDarkMode}}
          ...rest components
          </ThemeContext>
        </>

    )
}
