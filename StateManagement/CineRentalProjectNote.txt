How t create a valid url of a local file in Vite project?
Vite project e local file er valid URL create korar jonno URL constructor function ke call korte hoy. URL constructor duita param recieve kore zotha: file path and import.meta.url . then constructor URL er ref ke call korte hoy.
const getImageURL=(name)=>{
    return new URL('../assets/image/name, import.meta.url).ref
}
ekhane getImageURL function local file er ekta valid url return korebe, sei url er maddhome sei faile ke production e access kora zabe.
